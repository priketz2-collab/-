# 就活ナビ — 大学生のための就職活動 情報収集・管理ツール

ブラウザだけで動く、就職活動の情報収集・管理ツールです。ビルドやサーバーは不要で、
`index.html` を開くだけで使えます。データはお使いのブラウザ内（localStorage）にのみ保存され、
外部には送信されません。

## 使い方

1. このリポジトリをクローン／ダウンロードする
2. `index.html` をブラウザで開く（ダブルクリックでOK）
3. 「データ取込/管理」タブの **サンプルデータを読み込む** で動作を試せます

## 主な機能

| タブ | できること |
| --- | --- |
| **ダッシュボード** | 登録企業数・選考中・内定数などのサマリー、7日以内の予定、選考ファネルを表示 |
| **企業・求人** | 興味のある企業の業界・職種・勤務地・URL・関心度・メモを登録、検索・絞り込み・並び替え |
| **選考ステータス** | 各企業の選考段階（気になる→エントリー→ES提出→…→内定）をワンクリックで更新 |
| **スケジュール** | 説明会・ES締切・面接などのタスクを期日付きで管理。締切が近い／超過したものを色で強調 |
| **口コミ** | 先輩・OB訪問・説明会などで得た選考体験や社風の評判を企業ごとに蓄積 |
| **データ取込/管理** | JSON一括取り込み、サンプル読み込み、バックアップのエクスポート／インポート、全削除 |

## 情報の「自動収集」について

外部の求人サイトへ自動アクセス（スクレイピング）は行いません。各サイトの利用規約や
プライバシーへの配慮のためです。代わりに、求人サイトやスプレッドシートから書き出した
**JSON配列を貼り付けて一括取り込み**できます。フォーマットは画面の
「取り込みフォーマットを表示」ボタンで確認できます。

### 取り込みJSONの例

```json
[
  {
    "name": "サンプル株式会社",
    "industry": "IT・通信",
    "jobType": "ソフトウェアエンジニア",
    "location": "東京",
    "status": "気になる",
    "interest": 4,
    "url": "https://example.com/jobs",
    "nextAction": "本エントリー",
    "nextDate": "2026-07-01",
    "memo": "自由記述メモ"
  }
]
```

`name` 以外はすべて任意です。同名の企業は重複登録されません。

## データの保存とバックアップ

- データはブラウザの localStorage に保存されます（同じブラウザでのみ参照可能）
- 別のPCやブラウザに移行する場合は、**エクスポート**でJSONファイルを保存し、
  移行先で**インポート**してください
- ブラウザのデータを消去すると保存内容も消えるため、定期的なエクスポートを推奨します
