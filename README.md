# 就活ナビ — 大学生のための就職活動 情報収集・管理ツール

ブラウザだけで動く、就職活動の情報収集・管理ツールです。ビルドやサーバーは不要で、
`index.html` を開くだけで使えます。データはお使いのブラウザ内（localStorage）にのみ保存され、
外部には送信されません。

## 使い方

1. このリポジトリをクローン／ダウンロードする
2. `index.html` をブラウザで開く（ダブルクリックでOK）
3. 「データ取込/管理」タブの **サンプルデータを読み込む** で動作を試せます

## 主な機能

| タブ | できること |
| --- | --- |
| **ダッシュボード** | 登録企業数・選考中・内定数などのサマリー、7日以内の予定、選考ファネルを表示 |
| **企業・求人** | 興味のある企業の業界・職種・勤務地・URL・関心度・メモを登録、検索・絞り込み・並び替え。各カードの **🔍 リサーチ** から関連情報サイトへワンクリック |
| **選考ステータス** | 各企業の選考段階（気になる→エントリー→ES提出→…→内定）をワンクリックで更新 |
| **スケジュール** | 説明会・ES締切・面接などのタスクを期日付きで管理。締切が近い／超過したものを色で強調 |
| **口コミ** | 先輩・OB訪問・説明会などで得た選考体験や社風の評判を企業ごとに蓄積 |
| **面接対策** | 想定質問に対する自分の回答を準備・蓄積。定番質問のテンプレ追加、企業ひも付け、文字数カウント、コピー、「練習済み」チェック |
| **データ取込/管理** | JSON / CSV 一括取り込み、サンプル読み込み、バックアップのエクスポート／インポート、全削除 |

> 💡 ヘッダー右上の **🌙 / ☀️** ボタンでダーク／ライトテーマを切り替えできます（設定は保存されます）。

## 情報収集（🔍 リサーチ機能）

各企業カードの **🔍 リサーチ** ボタンを押すと、その企業名から組み立てた検索リンク集が開きます。

| カテゴリ | 飛べる先 |
| --- | --- |
| 🏢 公式・採用情報 | 公式採用ページ・募集要項、マイナビ／リクナビ検索 |
| 💬 口コミ・評判 | OpenWork、ライトハウス(en)、評判検索 |
| 📝 選考体験（ES・面接） | ONE CAREER、みんなの就職活動日記、ES・面接質問の検索 |
| 🔎 企業研究 | 最新ニュース、平均年収・待遇、業界・競合、IR・有価証券報告書 |

外部の求人サイトへ自動アクセス（スクレイピング）は行いません。各サイトの利用規約や
プライバシーへの配慮のため、「集める入口」をワンクリックで開く方式にしています。
各リンクは新しいタブで開きます。

## 一括取り込み（JSON / CSV）

求人サイトやスプレッドシートから書き出した **JSON配列** または **CSV** を貼り付けて一括取り込みできます
（先頭が `[` / `{` ならJSON、それ以外はCSVとして自動判定）。JSONフォーマットは画面の
「取り込みフォーマットを表示」ボタンで確認できます。CSVのヘッダー行には
`name,industry,jobType,location,status,interest,url,nextAction,nextDate,memo` が使えます
（`name` 以外は任意）。登録済みの企業は **CSVで書き出し**て Excel／スプレッドシートでも管理できます。

### 取り込みJSONの例

```json
[
  {
    "name": "サンプル株式会社",
    "industry": "IT・通信",
    "jobType": "ソフトウェアエンジニア",
    "location": "東京",
    "status": "気になる",
    "interest": 4,
    "url": "https://example.com/jobs",
    "nextAction": "本エントリー",
    "nextDate": "2026-07-01",
    "memo": "自由記述メモ"
  }
]
```

`name` 以外はすべて任意です。同名の企業は重複登録されません。

## データの保存とバックアップ

- データはブラウザの localStorage に保存されます（同じブラウザでのみ参照可能）
- 別のPCやブラウザに移行する場合は、**エクスポート**でJSONファイルを保存し、
  移行先で**インポート**してください
- ブラウザのデータを消去すると保存内容も消えるため、定期的なエクスポートを推奨します
